## K. 既知の制約（リリース時に明示する）

| 制約 | 影響 | 対応方針 |
| --- | --- | --- |
| `visit_count` はクライアント加算 | 連打で過大になる可能性 | ルールで ±1 に制限。次期に Cloud Functions 集計へ移行 |
| 同一神社・同日の重複チェックインを許容 | 参拝回数が実態より増える場合がある | 仕様として許容（「本日◯回」を表示） |
| App Check 未導入 | クライアント SDK の呼び出し元は未検証 | 次期導入 |
| 神社データの座標は概略値 | 300m 判定が境界付近で揺れる可能性 | 境界付近は精度注意を表示。データ整備を継続 |
| 写真の自動検査なし | 不正な画像が保存される可能性 | MIME・サイズのみ検証 |
| 通知・ランキング等は未実装 | — | 設計のみ考慮済み（設計書13章） |
